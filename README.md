## Что показывает

- общее число образцов;
- просроченные проверки;
- проверки на сегодня;
- проверки на ближайшие 7 дней;
- карточки образцов с точками 1 день, 1 неделя, 2 недели, 4 недели, 8 недель, 12 недель;
- последние внесенные pH, вязкость и внешний вид;
- ссылку на протокол исследования.
- аудит загруженных Excel-файлов;
- образцы, которые не сопоставились автоматически;
- форму внесения нового измерения;
- экспорт локальных внесений в CSV для переноса в Google Sheets.
- отправку измерений через Apps Script в главную таблицу;
- автоматическое создание листа `Мониторинг` в таблице-протоколе и добавление туда новых измерений.

## Запись в протоколы через Apps Script

Для записи в Google Sheets нужен один опубликованный Apps Script Web App. Его код находится в файле `google-apps-script.gs`.

При отправке измерения скрипт:

- добавляет строку в главную таблицу на лист `Внесенные измерения`;
- если у образца есть ссылка на протокол Google Sheets, открывает эту таблицу;
- создает в протоколе лист `Мониторинг`, если его еще нет;
- добавляет туда строку с датой, образцом, точкой, температурой, pH, вязкостью, внешним видом и комментарием;
- если указан лист Google Sheets и в нем есть матрица, дополнительно пытается записать pH/вязкость в матрицу.

У аккаунта, который публикует Apps Script, должны быть права редактирования всех протоколов, куда нужно записывать данные.

## Для публичной ссылки

Этот же сайт можно выложить на Vercel, Netlify или GitHub Pages. Для коллег Google Таблица должна быть доступна по ссылке хотя бы на чтение.

Для публикации нужны файлы:

- `index.html`
- `styles.css`
- `app.js`
- `source-inventory.json`
- `source-master-match.json`
- при необходимости `source-row-context.csv`
